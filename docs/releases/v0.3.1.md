A bug-fix release: edge cases in file reading, Git handling, Markdown fencing, and import resolution.

## Install without Rust

```bash
brew install pallaprolus/tap/contextcut
```

Or download the archive for your platform from this release:

| Platform | Archive target |
| --- | --- |
| macOS Apple Silicon | `aarch64-apple-darwin.tar.gz` |
| macOS Intel | `x86_64-apple-darwin.tar.gz` |
| Linux ARM64 | `aarch64-unknown-linux-musl.tar.gz` |
| Linux x86-64 | `x86_64-unknown-linux-musl.tar.gz` |
| Windows x86-64 | `x86_64-pc-windows-msvc.zip` |

All filenames start with `contextcut-0.3.1-`. Check the downloaded archive against `SHA256SUMS` before extracting it.

## Fixes

- `--diff` and `review` work before the first commit; unknown revisions get a clear error.
- A directory outside any Git repository honors its own `.gitignore`.
- Stdout write errors fail the run (a closed pipe is still ignored).
- Oversized files are read only up to the size cap.
- Unreadable subdirectories are counted in the `unreadable` total.
- `review --strip-comments` also strips deleted-file bodies.
- Indented backtick runs can no longer close a file's code fence early.
- Files with a NUL byte anywhere are treated as binary.
- Import graph: Rust file-module directories, Python subpackage `__init__.py`, literal JS/TS dynamic `import()`, and Go imports when `go.mod` is filtered out.
