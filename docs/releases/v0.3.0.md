ContextCut now prepares change reviews with the actual patch, changed files, and related context, with a token budget and clipboard output.

```bash
contextcut review --budget 45k --copy
```

## Install without Rust

```bash
brew install pallaprolus/tap/contextcut
```

Or download the archive for your platform from this release:

| Platform | Archive target |
| --- | --- |
| macOS Apple Silicon | `aarch64-apple-darwin.tar.gz` |
| macOS Intel | `x86_64-apple-darwin.tar.gz` |
| Linux ARM64 | `aarch64-unknown-linux-musl.tar.gz` |
| Linux x86-64 | `x86_64-unknown-linux-musl.tar.gz` |
| Windows x86-64 | `x86_64-pc-windows-msvc.zip` |

All filenames start with `contextcut-0.3.0-`. Archives contain the executable, README, and MIT license. Git is required for review/diff mode. Linux builds use musl; Windows bundles the C runtime statically. macOS binaries target macOS 11 or later.

Check the downloaded archive against `SHA256SUMS` before extracting it. On macOS use `shasum -a 256 <archive>`; on Linux use `sha256sum <archive>`; on Windows use `Get-FileHash <archive> -Algorithm SHA256`.

## Changes

- `review`: patch plus changed files and an import map, including staged changes, untracked additions, and deleted-file context.
- `--budget`: a limit on the complete Markdown output, measured with o200k_base. Review defaults to 20,000 tokens; required content is never silently omitted to meet the budget.
- `--copy`: clipboard delivery on macOS, Windows, Wayland, and X11.
- Prebuilt archives for five platforms, SHA-256 checksums, and a Homebrew formula generated from the released archives.
- Exclude local drafts and development metadata from the Cargo package.

This is an early-stage CLI. Import matching is heuristic, per-file truncation is marked in output, and Claude/Gemini token estimates are approximate. Smaller context packets do not establish better AI results. The experimental agent setup integration is not included in this release.
